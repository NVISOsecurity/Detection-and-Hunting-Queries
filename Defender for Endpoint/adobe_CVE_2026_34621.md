# Suspicious Communication with "Adobe Synchronizer" User-Agent - CVE-2026-34621 

## Description

CVE-2026-34621 is a zero-day vulnerability affecting Adobe Acrobat Reader. The flaw is triggered when a user opens a specially crafted malicious PDF, allowing embedded code to run while bypassing standard security protections without requiring further user interaction or elevated permissions. EXPMON’s analysis determined that the exploit leverages two privileged Acrobat APIs: util.readFileIntoStream() for accessing files on the victim’s system, and RSS.addFeed() to transmit data to attacker-controlled servers.
This query identifies external communication using based on HttpConnectionInspected events with user agent "Adobe Synchronizer", excluding legitimate Adobe domains.

## Query

### Defender for Endpoint

```
let KnownAdobeDomains = dynamic(["adobedtm.com", "acrobat.com", "adobe.io", "adobe.com", "adobelogin.com", "adobecc.com", "adobeexchange.com", "symantec.com", "amazontrust.com", "letsencrypt.org", "digicert.com", "verisign.com"]);
DeviceNetworkEvents
| where Timestamp >= ago(30d)
| where ActionType == 'HttpConnectionInspected'
| extend
    UserAgent = parse_json(AdditionalFields).user_agent,
    TargetDomain = parse_json(AdditionalFields).host
| where UserAgent contains "Adobe Synchronizer"
| where not(RemoteUrl has_any (KnownAdobeDomains) or TargetDomain has_any (KnownAdobeDomains)) //Exclude known Adobe domains
| where not(RemoteIP matches regex @"(?:10\.\d{1,3}\.\d{1,3}\.\d{1,3}|172\.(?:1[6-9]|2\d|3[0-1])\.\d{1,3}\.\d{1,3}|192\.168\.\d{1,3}\.\d{1,3})") //Exclude private IP ranges
```
