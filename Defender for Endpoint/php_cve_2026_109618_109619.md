# Suspicious Process Spawned by Web Service Process - PHP2Shell Post-Exploitation - CVE-2026-109618, CVE-2026-109619

## Description

This query identifies known suspicious processes user by adversaries or known suspicious process patterns spawned by Web Service processes. Based on recent PHP2Shell CVE-2026-109618, CVE-2026-109619, were an exploitation of PHP versions can lead to remote code execution (RCE), this query can be used for threat hunting purposes to identify suspicious processes spawned by Web Service processes.
